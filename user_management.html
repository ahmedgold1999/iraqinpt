تنبيه صلاحيات القراءة في Firebase Firestore

تتطلب قواعد حماية فايربيس (Firestore Rules) تسجيل الدخول كـ المشرف، أو السماح بالقراءة لجميع المشرفين والطلاب.

خيار 1 (الأسرع والأسهل): اضغط على زر وسجل دخول بحسابك الأدمن في التطبيق.
خيار 2 (إتاحة القراءة المباشرة من Firestore Rules):

افتح لوحة قواعد Firestore بـ Firebase Console واجعل سطر match /users/{userId} يتيح القراءة كالتالي:

match /users/{userId} { allow read: if true; allow write: if isAdmin(); }
